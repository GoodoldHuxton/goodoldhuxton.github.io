# goodoldhuxton.github.io

The personal developer site of GoodoldHuxton, hosted on GitHub Pages.

**Live:** https://goodoldhuxton.github.io

It is the public home for my projects and apps, including the publisher pages for **Putzkraft**, my storage cleaner and security checkup app for Android.

## Features

- Lightweight single-page site with no frameworks, no build step and no tracking
- Automatic light / dark theme that follows the visitor's system setting
- Mobile-friendly layout
- Hosts `app-ads.txt` for verifying the Android app with ad networks

## Tech Stack

- HTML, CSS
- GitHub Pages

## Installation

```bash
git clone https://github.com/GoodoldHuxton/goodoldhuxton.github.io.git
```

Open `index.html` in a browser. No build step is needed.

## Usage

Edit `index.html` and push to `main`. GitHub Pages publishes the change automatically within a minute.

## What problem it solves

Mobile app stores and ad networks require a verified developer website, a privacy policy URL and an `app-ads.txt` file. This repo provides all of that for free, with zero maintenance, on GitHub Pages.
